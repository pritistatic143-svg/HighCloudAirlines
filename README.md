# High Cloud Airlines Data Analysis

## Project Overview
This project analyzes airline operations, passenger trends, carrier performance, and flight routes using Excel dashboards and data analysis techniques.

## Tools Used
- Excel
- Pivot Tables
- Power Query
- VLOOKUP
- Dashboard Design

## KPIs
- Load Factor Percentage (Transported Passengers / Available Seats)
- Yearly Load Factor Analysis
- Quarterly Load Factor Analysis
- Monthly Load Factor Analysis
- Carrier-wise Load Factor Percentage
- Top 10 Carrier Names Based on Passenger Preference
- Top Flight Routes Based on Number of Flights
- Weekend vs Weekday Load Factor Analysis
- Number of Flights by Distance Group
- Source to Destination Flight Search Analysis

## Date Calculations
Created Date Field using:
- Year
- Month
- Day

Derived Fields:
- Year
- Month Number
- Month Full Name
- Quarter (Q1, Q2, Q3, Q4)
- Year-Month (YYYY-MMM)
- Weekday Number
- Weekday Name
- Financial Month
- Financial Quarter

## Insights
- Identified peak travel periods and high load factor months
- Analyzed most preferred airline carriers by passengers
- Evaluated busiest flight routes and distance groups
- Compared weekend and weekday flight occupancy trends
- Improved route and operational analysis using dashboard filters

## Dashboard Features
- Interactive Filters
- Source to Destination Search Capability
- Carrier-wise Analysis
- Route-wise Flight Analysis
- Time-based Trend Analysis
